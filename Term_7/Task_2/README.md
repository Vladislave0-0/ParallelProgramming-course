# Lock-Free Очередь (Алгоритм Майкла–Скотта)

Реализация потокобезопасной очереди без блокировок (`lock-free queue`) на основе классического алгоритма **Майкла и Скотта (1996)** с использованием атомарных операций C++.

Прочитать об алгоритме можно [здесь](https://neerc.ifmo.ru/wiki/index.php?title=%D0%9E%D1%87%D0%B5%D1%80%D0%B5%D0%B4%D1%8C_%D0%9C%D0%B0%D0%B9%D0%BA%D0%BB%D0%B0_%D0%B8_%D0%A1%D0%BA%D0%BE%D1%82%D1%82%D0%B0).


## Особенности реализации:
Будем реализовывать очередь по алгоритму Майкла & Скотта, в котором используются атомарные операции для обеспечения потокобезопасности без блокировок. 
- Для упрощения обработки пустой очереди будем использовать `dummy-узел`. 
- Защита от `false sharing`: указатели `head` и `tail` выровнены по границе кэш-линии (`alignas(64)`).

## Ограничения:
- `ABA`-проблема присутствует и в реалиях данной задачи не может быть решена малой кровью.
- Деструктор не потокобезопасен, поэтому его стоит вызывать, когда очередь точно не используется. 
<br><br>
# Требования
CMake с версией не меньше 3.11
<br><br>
# Компиляция и запуск
```powershell
cmake -S ./ -B build/ -DCMAKE_BUILD_TYPE=Release
cmake --build build/
```

**Запуск проекта/тестов**:
```powershell
./build/queue_tests
```
