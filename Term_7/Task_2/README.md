# Задача

Реализовать `lock-free` очередь с помощью атомарных операций.

## Особенности реализации:
Будем реализовывать очередь по алгоритму Майкла & Скотта, в котором используются атомарные операции для обеспечения потокобезопасности без блокировок. Для упрощения обработки пустой очереди будем использовать dummy-узел.
<br><br>
# Требования
CMake с версией не меньше 3.11
<br><br>
# Компиляция и запуск
```powershell
cmake -S ./ -B build/ -DCMAKE_BUILD_TYPE=Release
cmake --build build/
```

**Запуск проекта/тестов**:
```powershell
./build/bin/ThreadSafeCounter
```
